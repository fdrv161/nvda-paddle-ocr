Paddle OCR

Распознаёт текст на экране моделями PaddleOCR. Работает так же, как встроенный Windows OCR (NVDA+R), но обычно читает точнее, особенно мелкий текст и тёмные темы. Всё работает без интернета.

Нужна NVDA 2026.3 или новее.

Команды

Жестов по умолчанию нет. Назначьте их сами: меню NVDA, Параметры, Жесты ввода, категория «Paddle OCR».

  • Распознаёт содержимое текущего объекта навигатора. Открывает окно с результатом, как NVDA+R. По тексту можно ходить стрелками, Enter щёлкает по слову, Escape закрывает окно.
  • Переключает язык распознавания: английский или русский.
  • Открывает настройки Paddle OCR.

При первом распознавании прозвучит «Загрузка моделей OCR»: модели загружаются в память один раз, потом распознавание быстрое.

Языки

  • Английский — лучшая точность для английского и других языков на латинице. Русский текст в этом режиме не читается.
  • Русский — читает и русский, и английский текст, но английский немного хуже, чем в режиме «Английский».

Если программа на английском, включите английский; если на русском — русский. По умолчанию язык берётся из языка NVDA.

Настройки

Меню NVDA, Параметры, Настройки, категория «Paddle OCR».

  • Язык распознавания: как у NVDA, английский или русский.
  • Периодически обновлять распознанное содержимое: окно результата само обновляется, пока открыто. Выключено по умолчанию.
  • Читать всё после распознавания: результат читается сразу целиком. Включено по умолчанию.

Шторка экрана

Как и Windows OCR, дополнение умеет распознавать при включённой шторке, если это поддерживает Windows. Если не поддерживает, NVDA попросит временно отключить шторку.

Лицензии

Модели PaddleOCR (PP-OCRv6, PP-OCRv5 eslav) — Apache 2.0. Библиотеки: onnxruntime (MIT), NumPy (BSD), OpenCV (Apache 2.0). Полные тексты лицензий лежат в папке дополнения: licenses, а также рядом с каждой библиотекой в globalPlugins\paddleOcr\lib.
