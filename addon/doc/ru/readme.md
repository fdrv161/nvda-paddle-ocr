# Paddle OCR

## О дополнении

Paddle OCR — это альтернатива встроенному Windows OCR (NVDA+R) для [NVDA](https://www.nvaccess.org/) 2026.3 и новее. Дополнение использует компактные модели распознавания от Baidu ([PaddleOCR](https://github.com/PaddlePaddle/PaddleOCR), [Apache 2.0](https://www.apache.org/licenses/LICENSE-2.0)), которые работают локально через [onnxruntime](https://github.com/microsoft/onnxruntime) прямо внутри NVDA — без интернета и сторонних приложений. Движок точнее читает мелкий шрифт и текст на тёмном фоне. Окно результата и поведение при включённой шторке экрана привычны для NVDA.

## Команды и управление

Горячих клавиш по умолчанию нет, чтобы не конфликтовать с другими дополнениями. Назначить их можно в меню NVDA: Параметры → Жесты ввода → категория «Paddle OCR».

* **Распознать объект навигатора.** Открывает окно результата: стрелки ходят по тексту, Enter щёлкает по слову, Escape закрывает окно.
* **Переключить язык распознавания:** латиница или кириллица.
* **Открыть настройки Paddle OCR.**

При первом вызове за сеанс прозвучит «Загрузка моделей OCR». На процессорах вроде Ryzen 7 7840HS весь экран распознаётся примерно за 0,4 секунды, а небольшие окна — за доли секунды. На слабом железе это займёт больше времени.

## Языки и алфавиты

Дополнение работает в двух режимах, по алфавитам:

* **Латиница:** английский, немецкий, французский, испанский, польский и другие. Максимальная точность, но кириллица не распознаётся.
* **Кириллица:** русский, украинский, белорусский, болгарский, сербский, казахский, татарский, башкирский и другие. Английский текст тоже распознаётся, но точность немного ниже, чем в режиме «Латиница».

По умолчанию режим выбирается по языку NVDA. Если NVDA на русском, украинском, белорусском или болгарском, буквы других кириллических алфавитов отключены, чтобы в текст не попадали случайные артефакты вроде «һ» вместо «н».

## Настройки

Меню NVDA: Параметры → Настройки → категория «Paddle OCR».

* **Язык распознавания:** по языку NVDA, латиница или кириллица.
* **Периодически обновлять распознанное содержимое:** окно результата само перечитывается, пока открыто. Нагружает процессор всё это время, поэтому по умолчанию выключено.
* **Читать всё после распознавания:** текст озвучивается сразу целиком. Если привык читать вручную, выключи. По умолчанию включено.

## Ограничения и нюансы

* Иконки и рамки интерфейса иногда распознаются как случайные символы вроде «x», «o», «+».
* Короткие одиночные слова из букв, одинаковых в обоих алфавитах, иногда читаются не теми буквами.
* Нужна системная библиотека `MSVCP140_1.dll`. Если при распознавании звучит ошибка, а в журнале NVDA упоминается эта библиотека, установи пакет [Microsoft Visual C++ Redistributable](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist?view=msvc-170) с сайта Microsoft.

## История версий

### 1.0.5

* Новая модель для кириллицы: меньше ошибок в смешанных строках и поддержка новых языков (сербский, македонский, казахский и др.).
* Надёжное распознавание мелких объектов (кнопок, подписей): текст у самых краёв больше не теряется.
* Меньше потребление памяти, обработка немного быстрее.

### 1.0.4

* Команда распознавания теперь говорит и в режиме речи «по запросу».
* Код приведён к стандартам NVDA.

### 1.0.3

* Режимы переименованы по типу письменности: «Латиница» и «Кириллица».
* Автоматическое включение кириллицы при украинской, белорусской и болгарской локализации NVDA.
* В справку добавлен список поддерживаемых языков.

### 1.0.2

* В дополнение добавлены лицензия GPL, ссылка на репозиторий и список изменений.
* Русская и английская справка стали короче и проще.

### 1.0.1

* Распознавание стало быстрее.

### 1.0.0

* Первый выпуск: распознавание, два языка, настройки, перевод интерфейса и справки.
