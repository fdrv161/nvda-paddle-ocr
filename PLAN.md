# План: дополнение NVDA «Paddle OCR» (минимум NVDA 2026.3, 64 бит)

## Зачем
Windows OCR в NVDA часто ошибается. PaddleOCR (PP-OCRv6) читает заметно лучше. Делаем дополнение,
которое работает **так же, как Windows OCR**, только с другим движком. Главное — скорость и стабильность.

## Почему 2026.3
В 2026.3 захват для OCR работает при шторке и встроенной лупе (#20630, #20664). Если система так не умеет,
NVDA сама просит отключить шторку. Мы получаем это бесплатно, потому что идём через стандартный `contentRecog.recogUi`.

## Как устроено
- Всё на Python внутри NVDA, без своих .exe.
- В `lib/` лежат колёса cp313 win_amd64: `onnxruntime 1.30.0`, `numpy 2.5.3`, `opencv-python-headless 5.0.0.93`.
- Свой короткий конвейер по образцу rapidocr: найти строки → прочитать строки.
- Свой `ContentRecognizer` → `recogUi.recognizeNavigatorObject()` → `LinesWordsResult`.
  Окно результата, клик по слову, автообновление и шторка — всё как у NVDA+R.

## Модели (все внутри)
- Детектор строк: det_v6_tiny (small пробовали: не точнее, на 30% медленнее, склеивает колонки).
- Режим «Латиница»: rec_v6_small, только латиница (иначе иконки читаются как иероглифы). Кириллицу не читает.
- Режим «Кириллица»: rec_cyrillic_v5 (33 кириллических языка и английский). Ошибок меньше, чем у eslav_v5,
  особенно в строках вперемешку с латиницей.
- Буквы в «Кириллице» зависят от языка NVDA: русский, украинский, белорусский, болгарский — только их буквы;
  другие кириллические языки — вся современная кириллица. Старославянские буквы запрещены всегда.
- Режим выбирает пользователь, по умолчанию — по языку NVDA. Автовыбор по строкам пробовали: сложно и теряет русские слова.
- PP-OCRv6 для кириллицы нет; русские модели vladlinv хуже на экранах (tiny) или слишком медленные (medium).
- Точность меряем `tools/accuracy.py` (картинки с известным текстом).

## Как у Windows OCR
- Три команды, все без жеста по умолчанию: «Распознать объект навигатора», «Переключить режим», «Настройки».
- Настройки: режим, автообновление, читать результат сразу.
- На защищённом экране дополнение отключается целиком: ни команд, ни настроек.

## Загрузка и память
- Библиотеки и модели загружаются при первом запросе, а не при старте NVDA (загрузка 0.1–0.2 с).
- После загрузки модели остаются в памяти, поэтому следующие запросы быстрые.
- Детектор без арены памяти; распознаватель отдаёт память системе после последней пачки строк,
  пачки идут от широких к узким. numpy грузится с одним потоком OpenBLAS.
- Итог в NVDA: около +100 МБ после распознавания, потоков 39 вместо 55. Выгрузка моделей не нужна.

## Стабильность
- Распознавание в фоновом потоке; один запрос за раз.
- Ошибка → сообщение и запись в журнал, NVDA продолжает работать.
- MSVCP140_1.dll не кладём (как в OnnxASR): она почти везде уже есть.

## Координаты (чтобы клик попадал)
- Если картинку уменьшаем для детектора, рамки умножаем обратно на тот же коэффициент.
- Маленькие картинки (меньше 100 пикселей) получают поле 16 пикселей цветом фона, иначе текст у края теряется.
- Рамки на одной высоте собираем в одну строку и сортируем слева направо.
- Слова внутри рамки делим по позициям букв.
- Тест: текст в известных местах на картинках 1080p и 4K. Рамки слов должны совпасть.

## Файлы `paddleOcr/`
- `addon/globalPlugins/paddleOcr/`
  - `__init__.py` — команды, настройки
  - `recognizer.py`
  - `engine.py` — без NVDA, можно тестировать отдельно
  - `lib/`, `models/`
- `tools/` — скачать библиотеки и модели, сборка, замеры; `tests/`. Для разработки — `.venv` проекта.

## Этапы
0. Замеры вне NVDA — **готово**. INT8 и урезанные модели не берём (медленнее или портят текст).
   Потоки — авто, пачка строк — 4. Слова только из букв-двойников (Bce/Все, Сору/Copy) пишутся азбукой
   соседей или экрана; I/l чинятся правилами. Неустранимо: одиночное слово-двойник на экране другого языка.
1. Команда → окно результата, клик по словам — **готово, проверено в NVDA**.
2. Режимы и команда переключения — **готово, проверено в NVDA**.
3. Настройки, перевод на русский, документация ru/en — **готово, проверено в NVDA**.
4. Выпуски 1.0.0–1.0.4 на GitHub — **готово**. Старт, журнал, память проверены в NVDA.
5. Версия 1.0.5: модель cyrillic_v5, маленькие объекты, меньше памяти, защищённый экран — **готово**.
